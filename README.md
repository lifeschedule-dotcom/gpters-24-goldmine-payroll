# 북부대공의 금광: 1주차 AI 실습 자료

**현재 실습의 시작 파일은 [북부성 금광 정산: 소설 속 임무와 규칙](00_북부성_실습_상황.md)입니다.** 참가자는 북부대공의 안주인이 되어 ChatGPT 또는 Claude와 함께 금광 인부 네 명의 정산 문제를 풀어 갑니다. 완성된 요청문을 복사해서 보내는 방식이 아니라, 강사의 화면을 보며 직접 말하고 AI의 답을 확인합니다.

등장인물과 급여·세금 규칙은 **소설 속 가상 설정**입니다. 실제 대한민국의 급여 지급이나 세금 신고에 사용하지 마세요.

## 수업 전에 준비할 것

- 사전 세팅 1강에서 만든 **OneDrive의 `me` 폴더 안 `Obsidian Vault`**를 Obsidian으로 열어 둡니다. 경로 모양은 `내 OneDrive/me/Obsidian Vault`입니다. 보관함은 MD 노트를 담는 폴더입니다. 이미 다른 위치에 보관함을 만들었다면 새 보관함을 중복 생성하지 말고 자신이 쓰는 보관함을 확인합니다.
- ChatGPT 또는 Claude에 로그인합니다. Git 설치, GitHub 계정, Google Apps Script 설정은 이 실습에 필요하지 않습니다.
- Zoom 공유 화면과 AI 창을 나란히 띄울 수 있게 준비합니다.

## 수업에서 MD 파일 열기

1. 위의 **북부성 금광 정산** 링크를 열고 GitHub의 **Download raw file** 버튼으로 `00_북부성_실습_상황.md` 파일을 저장합니다. 버튼이 보이지 않으면 이 저장소의 **Code → Download ZIP**을 내려받아 압축을 풀고, 그 안에서 같은 이름의 MD 파일 하나만 찾습니다.
2. Obsidian 왼쪽 파일 탐색기 위쪽의 **새 폴더** 버튼을 눌러 **현재 `Obsidian Vault` 안에** `지피터스 스터디자료` 폴더를 만듭니다.
3. 다운로드한 MD 파일을 그 폴더에 넣습니다. 파일 탐색기에서 Obsidian 왼쪽의 `지피터스 스터디자료` 폴더로 끌어 놓을 수 있습니다. 사전 세팅 1강의 배치를 따른 경우 파일 위치는 `내 OneDrive/me/Obsidian Vault/지피터스 스터디자료/00_북부성_실습_상황.md`입니다. **`me` 바로 아래에만 넣으면 Obsidian의 `Ctrl+O`에서 찾을 수 없습니다.**
4. Obsidian에서 **Ctrl+O**(Mac은 Cmd+O)를 누르고 `북부성`을 검색해 파일을 엽니다. 검색 결과가 없으면 파일이 현재 보관함의 폴더에 들어갔는지 확인합니다.

## AI와 시작하기

열어 둔 MD 파일을 ChatGPT 또는 Claude의 새 채팅에 첨부합니다. 앱에서 `.md` 첨부가 안 되면 Obsidian에서 문서 내용을 모두 선택해 채팅창에 붙여 넣어도 됩니다. **배경자료만 전달하고, AI에게 무엇을 시킬지는 강사와 함께 직접 문장으로 적습니다.**

사전 세팅 1강처럼 데스크톱 AI의 **로컬 작업 폴더로 `me`를 이미 선택**했고 그 기능이 켜져 있다면, `me` 안의 이 실습 MD를 읽도록 요청할 수도 있습니다. 일반 채팅이나 클라우드 프로젝트는 `me`를 자동으로 읽지 않으므로 위의 파일 첨부 경로를 사용합니다. 로컬 작업 기능이 없는 참가자도 공통 실습을 할 수 있습니다.

수업 영상은 [도입](video/북부성_실습_인트로.mp4) → 실습 → [5초 엔딩](video/북부성_실습_5초_엔딩.mp4) 순서입니다. 화면에서 글자가 작으면 강사가 보여 주는 자료와 다운로드한 MD 파일을 참고하세요.
